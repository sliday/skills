# Judge rubric (D1-D8, score 0-2 each; 0 absent, 1 partial, 2 solid)

Score each report per dimension with a one-line justification and a short
verbatim quote. Then total /16.

D1 Gate rigor: every hard gate verified per candidate, not assumed; gates
   applied before rating rank.
D2 Rating skepticism: normalization, spread, source agreement, syndication
   reasoning vs trusting one headline score.
D3 Negative evidence: dealbreaker-targeted queries on EVERY finalist; three
   strongest negatives or honest absence; symmetric coverage.
D4 Provenance: claims labeled source-visible / tool-derived / corroborated /
   assumed; acquisition commands cited for tool figures.
D5 Price honesty: decision-grade vs indicative separated; no budget arithmetic
   on indicative prices; UNVERIFIED stated when blocked.
D6 Decision quality: one winner, conditional fallback, reasoned rejections,
   watch-outs with mitigations, explicit uncertainty and flip conditions.
D7 Ground-truth recovery (anchor briefs only): the anchor hotel appears with
   an explicit gate verdict; omission is reasoned, not silent.
D8 Reproducibility: cited tool figures replay and match; irreproducible
   precision (review counts, deep URLs, ids) scores 0. Judge receives a
   verified-facts block; never assume tool availability.
